# Helpdesk Ticket Bot (GitLab Version)

Этот бот предназначен для автоматического создания тикетов (Issue) в GitLab на основе сообщений из Telegram.

## Основные возможности
- Создание тикетов в GitLab из текстовых сообщений Telegram.
- Поддержка вложений: изображения и документы загружаются в проект GitLab и прикрепляются к тикету.
- Автоматическое определение автора (если сообщение переслано или прислано напрямую).
- Проверка прав доступа по Telegram User ID.

## Установка

1. Склонируйте репозиторий.
2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
3. Создайте файл `.env` на основе `.env.example` и заполните необходимые данные:
   - `TELEGRAM_BOT_TOKEN`: Токен вашего бота от BotFather.
   - `ALLOWED_USER_ID`: Ваш Telegram ID (бот будет отвечать только вам).
   - `GITLAB_URL`: URL вашего инстанса GitLab (например, `https://gitlab.kama.gs`).
   - `GITLAB_PROJECT_ID`: ID проекта в GitLab или его полный путь (path with namespace).
   - `GITLAB_TOKEN`: Personal Access Token с правами `api`.

## Запуск

Запустите бота командой:
```bash
python gitlab_bot.py
```

## Использование

Просто отправьте или перешлите сообщение боту. Первая строка сообщения станет заголовком тикета, остальной текст — описанием. При наличии вложений они будут автоматически добавлены в описание тикета.
