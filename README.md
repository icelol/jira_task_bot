# Telegram Бот для создания тикетов

Этот репозиторий содержит два Telegram бота для автоматического создания тикетов в системах управления проектами.

## 🎯 Описание

Проект содержит два основных модуля:

- **`gitlab_bot.py`** — бот для создания **Issue** в GitLab
- **`jira_bot.py`** — бот для создания **Ticket** в Jira

Оба бота позволяют:
- Создавать тикеты из текстовых сообщений Telegram
- Загружать вложения (изображения, документы)
- Автоматически определять автора сообщения
- Проверять права доступа по Telegram User ID

---

## 📋 Требования

- Python 3.8+
- Telegram бот (создать через [BotFather](https://t.me/botfather))
- Аккаунт GitLab или Jira с правами на создание тикетов
- Personal Access Token или учетные данные для авторизации

## 🚀 Установка

### 1. Клонирование репозитория

```bash
git clone https://gitlab.kama.gs/a.pikhterev/helpdesk_ticket_bot.git
cd helpdesk_ticket_bot
```

### 2. Создание виртуального окружения

```bash
python3 -m venv .venv
source .venv/bin/activate  # На Windows: .venv\Scripts\activate
```

### 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 4. Настройка переменных окружения

Скопируйте `.env.example` в `.env` и заполните необходимые значения:

```bash
cp .env.example .env
```

Затем отредактируйте `.env` с вашими данными.

## ⚙️ Настройка переменных окружения

### Для обоих ботов (обязательные):

```env
# Telegram Bot Settings
TELEGRAM_BOT_TOKEN=<ваш_токен_от_BotFather>
ALLOWED_USER_ID=<ваш_Telegram_ID>
```

**Как получить TELEGRAM_BOT_TOKEN:**
1. Напишите [@BotFather](https://t.me/botfather)
2. Команда `/newbot` для создания нового бота
3. Скопируйте полученный токен

**Как получить ALLOWED_USER_ID:**
- Напишите боту [@userinfobot](https://t.me/userinfobot) и он покажет ваш ID

---

### Для GitLab бота (`gitlab_bot.py`):

```env
# GitLab Settings
GITLAB_URL=https://gitlab.kama.gs              # URL вашего инстанса GitLab
GITLAB_PROJECT_ID=123                          # ID проекта или полный путь (path/with/namespace)
GITLAB_TOKEN=<ваш_Personal_Access_Token>       # Токен с правами 'api'
```

**Как получить GITLAB_TOKEN:**
1. Перейдите в **GitLab → Профиль → Access Tokens**
2. Создайте новый токен с правами `api`
3. Скопируйте его в `.env`

---

### Для Jira бота (`jira_bot.py`):

```env
# Jira Settings
JIRA_SERVER=https://jira-it.kama.gs           # URL вашего Jira сервера
JIRA_PROJECT_KEY=HD                            # Ключ проекта в Jira (2-3 символа)
JIRA_ISSUE_TYPE=Ticket                         # Тип задачи (Task, Bug, Story и т.д.)
JIRA_CONTACT_FIELD=customfield_10000           # ID кастомного поля (опционально)
```

**Авторизация (выберите ОДИН способ):**

**Вариант 1: Personal Access Token (рекомендуется):**
```env
JIRA_PAT=<ваш_Personal_Access_Token>
```

**Вариант 2: Логин и пароль:**
```env
JIRA_USERNAME=<ваше_имя_пользователя>
JIRA_PASSWORD=<ваш_пароль_или_API_token>
```

**Как получить JIRA_PAT:**
1. Перейдите в **Jira → Профиль → API Token**
2. Создайте новый токен
3. Скопируйте его в `.env`

## 💬 Использование

### Как создать тикет:

1. **Откройте Telegram** и найдите вашего бота
2. **Отправьте сообщение:**
   - **Первая строка** — заголовок тикета
   - **Остальной текст** — описание задачи
3. **Приложите файлы** (опционально):
   - Изображения (фото)
   - Документы (PDF, Excel, Word и т.д.)

### Примеры:

**Пример 1 - Простой текст:**
```
Ошибка при загрузке профиля
Когда я пытаюсь открыть профиль, приложение вылетает с ошибкой 404
```

**Пример 2 - С вложением:**
```
Неправильное отображение на мобильном устройстве
Кнопка "Сохранить" выходит за пределы экрана. Вложу скриншот ошибки.
```
(+ отправить скриншот)

## 🐛 Решение проблем

### Ошибка: "TELEGRAM_BOT_TOKEN не указан"
**Решение:** Проверьте, что `.env` файл создан и заполнен правильно.

### Ошибка подключения к GitLab/Jira
**Решение:** 
- Проверьте URL сервера
- Убедитесь, что токен актуален
- Проверьте права доступа токена

### Файлы не загружаются в GitLab/Jira
**Решение:** 
- Убедитесь, что у вас есть права на загрузку файлов в проект
- Проверьте размер файла (может быть ограничение)
